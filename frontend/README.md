# Frontend

React + TypeScript + Material UI + React Router.

```powershell
npm ci
npm run dev
```

Проверка типов и сборка: `npm run build`.

Структура модулей, сценарии, ограничения локального хранилища и описание третьей лабораторной находятся в [основном README](../README.md). Скриншоты: [docs/screenshots](docs/screenshots).
