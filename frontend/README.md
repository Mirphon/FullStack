# Осмотр авто

оценка повреждений подержанных автомобилей по фотографии.

Пользователь вводит сведения об автомобиле и прикрепляет фотографию, на которой автомобиль виден целиком. В дальнейшем данные можно передать модели для определения характера и степени повреждений.

## Экраны и сценарий

1. Начало (`/`) — краткое описание и кнопка «Начать осмотр».
2. Автомобиль (`/car`) — марка, модель, год выпуска и необязательный тип кузова.
3. Фотография (`/photo`) — данные автомобиля, выбор файла, предпросмотр, замена и удаление.
4. Вход (`/login`) — электронная почта и пароль.
5. Регистрация (`/register`) — имя, электронная почта, пароль и его повторение.

Страницы аккаунта доступны по ссылкам в боковой панели. Формы проверяют заполнение, формат почты, длину пароля при регистрации (от 8 символов) и совпадение паролей. Пока реализован только интерфейс: аккаунты не создаются, вход не выполняется, данные не отправляются и пароли не сохраняются в браузерном хранилище. После проверки формы выводится соответствующее сообщение. Осмотр автомобиля остаётся доступен без аккаунта.

Основной сценарий: начать осмотр → заполнить форму → выбрать фотографию. Можно вернуться и изменить данные. При переходах данные сохраняются в состоянии React, после обновления страницы сбрасываются. Адрес фотографии без заполненной формы перенаправляет на `/car`, неизвестный адрес — на главную.

Марка и модель не должны быть пустыми. Год — от 1900 до текущего. Допускаются JPG, PNG и WebP размером до 10 МБ.

## Запуск

Нужны Node.js 22.12+ или 24 и npm. В папке с `package.json`:

npm ci
npm run dev

Проверка типов и сборка:

npm run build

Просмотр собранного приложения:

npm run preview

Результат сборки находится в `dist`. При размещении на сервере нужно настроить возврат `index.html` для клиентских маршрутов.

## Стек и структура

React, TypeScript, Vite, React Router, Material UI. Кнопки, поля, выпадающий список и сообщения об ошибках взяты из Material UI.

src/
  components/Layout.tsx — боковая панель, заголовок и этапы
  pages/HomePage.tsx    — главная страница
  pages/CarPage.tsx     — форма автомобиля
  pages/PhotoPage.tsx   — выбор фотографии
  pages/AuthPage.tsx    — формы входа и регистрации
  App.tsx              — маршруты и общее состояние
  main.tsx             — запуск приложения и тема Material UI
  types.ts             — тип автомобиля и проверка данных
  styles.css           — стили и адаптивность
docs/screenshots/      — скриншоты

`node_modules` создаётся при установке, `dist` — при сборке. Эти папки исключены из Git.

## Изменения

Номера в боковой панели отображаются без ведущего нуля. Увеличены логотип, название, ссылки аккаунта, заголовки и описания в тёмной панели. Кружки на главной странице увеличены до 128 пикселей на широком экране и 66 пикселей на телефоне.

На главной странице увеличены кружки этапов, цифры и подписи под ними. Стрелки выровнены по центру кружков; на телефонах используются отдельные размеры. Оформление шагов на остальных страницах сохранено.

Добавлены страницы входа и регистрации в прежней серо-янтарной стилистике. Общий компонент формы используется для двух маршрутов, чтобы не дублировать поля почты и пароля. На этих страницах скрыт индикатор этапов осмотра. Существующие формы автомобиля и фотографии не изменены.

Проверка TypeScript прошла. Обычная сборка в среде проверки остановилась с ошибкой доступа EPERM при определении пути; сборка с временной настройкой preserveSymlinks завершилась успешно. Конфигурация проекта оставлена прежней. Браузерная проверка и обновление скриншотов не выполнены: браузер проверки не смог подключиться к локальному серверу. Существующие скриншоты показывают предыдущую версию боковой панели.

Для проверки новых экранов: откройте `/login` и `/register`, отправьте пустые формы, укажите неверную почту и несовпадающие пароли, затем заполните поля корректно. Проверьте сообщение о необходимости сервера, ссылки между формами и возврат на главную. При смене формы введённые данные очищаются.
