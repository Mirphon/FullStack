Frontend разделён по назначению:
- `src/app` — маршруты приложения, общее состояние автомобиля и фотографии, стили.
- `src/pages` — страницы начала, автомобиля, фотографии, входа, регистрации и истории.
- `src/features` — формы автомобиля и аккаунта, выбор фотографии, сохранение осмотра.
- `src/entities` — типы автомобиля и осмотра, проверка автомобиля, репозиторий осмотров.
- `src/shared/ui` — общий макет и компонент состояний данных.
- `src/main.tsx` — точка входа, подключение темы Material UI и маршрутизатора.

Используется упрощённая структура FSD. Страницы собирают пользовательские действия, действия используют сущности, общие компоненты не зависят от страниц. Полное соблюдение FSD не требуется. Состояние полей хранится через useState, побочные действия - через useEffect. Пропсы и данные типизированы TypeScript.
